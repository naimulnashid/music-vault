# Music Vault landing page

A single static page, built with Astro, that introduces Music Vault and links to the setup
guides. It is deployed as its own Vercel project with Root Directory `apps/site`.

```sh
npm run site:dev      # from the repository root: http://localhost:4321
npm run site:build    # static output in apps/site/dist
npm run site:check    # type-check
```

Setup, deployment, security headers and where to edit each part:
[docs/site-setup.md](../../docs/site-setup.md).
